# 数据项目作品集（Data Projects Portfolio）

作者：顾文涛

本仓库用于展示个人完成的数据分析与数据可视化相关项目，主要涉及 Power BI、Python、JavaScript 等工具，通过对数据进行整理、分析与可视化展示，从数据中提取有价值的信息。

## 项目列表

### 1. Spotify 商业数据分析仪表板
工具：Power BI / Excel  
基于 Spotify 2017–2023 年业务数据，对收入增长趋势、收入结构以及用户指标进行分析，并构建可视化分析仪表板。

### 2. Cookie Cats A/B Test 实验分析海报
工具：Python / Pandas / Matplotlib  
通过 A/B Test 方法分析游戏版本调整对玩家留存率的影响，并对 Day1 与 Day7 留存率进行对比分析。

### 3. 中国人口受教育情况数据可视化
工具：Python / JavaScript / Chart.js  
基于人口普查数据，对中国人口受教育情况进行统计与可视化展示，分析不同年龄、城乡及文化水平结构。
